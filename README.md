# ClickShow

ClickShow 是一款 Windows 鼠标点击提示工具。点击鼠标时，光标周围会出现短暂的彩色波纹，方便展示操作位置。

- **语言**：C#、.NET 10
- **界面**：WinUI 3（Windows App SDK）
- **动画**：Windows Composition
- **安装**：由 Inno Setup 制作安装包

## 安装

下载并运行适合自己的安装包：

| 版本                                 | 适用                                                              |
| ------------------------------------ | ----------------------------------------------------------------- |
| 标准版（`ClickShow-x.x.x.exe`）      | 推荐，适合已安装 .NET 10 的用户；缺少组件时，安装程序会提示下载。 |
| 完整版（`ClickShow-x.x.x-Full.exe`） | 适配更多用户使用，已包含运行所需 .NET 等组件，安装包体积较大。    |

安装完成后，可从桌面或开始菜单启动 ClickShow。默认不会开机自启；如有需要，可在设置中开启。卸载时可以选择是否一并删除个人设置，默认保留。

## 使用

ClickShow 启动后常驻系统托盘：

- 左键点击托盘图标，打开设置。
- 右键点击托盘图标，可启用或停用波纹、打开设置、访问项目页面或退出程序。
- 关闭设置窗口只会隐藏窗口；需要完全退出时，请使用托盘菜单中的“退出”。

左键、中键、右键和侧键都可以分别启用，并设置各自的波纹颜色。按下鼠标时会显示波纹；按住超过半秒，或拖动超过 200 像素后松开，还会在松开位置显示较小的波纹。

在设置中可以调整波纹大小和动画方式，也可以开启“开机自启”。修改外观后会自动保存，无需手动点击保存按钮。

## 管理员权限

如需以管理员权限运行 ClickShow，可在设置中开启“管理员权限”，然后点击出现的“重启应用”。Windows 可能会要求确认提权。关闭该选项后，同样需要点击“重启应用”才能切换回普通权限。

## 配置文件

个人设置保存在 `%LocalAppData%\ClickShow\settings.json`。
